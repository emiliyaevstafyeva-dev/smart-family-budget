# Умный семейный бюджет

Браузерный калькулятор семейного бюджета: доходы, резервы под обязательные платежи, 25% накоплений и дневной лимит свободных денег. Работает на компьютере и телефоне, данные хранятся локально в браузере.

## Возможности

- **Регулярные доходы** — несколько источников с фиксированными днями месяца; суммы можно задавать отдельно для каждого месяца.
- **Постоянные расходы** — кредиты, ЖКХ, связь и др.; каждый месяц создаётся отдельное обязательство со своим резервом.
- **Разовые крупные траты** — стоматолог, ремонт и т. п. с конкретной датой.
- **Повседневные расходы** — фактические траты по дням (только из свободных денег).
- **Накопительное резервирование** — при каждом доходе формируется доля в резерв будущих платежей; в карточке видно «было → добавить → стало».
- **Безопасный дневной лимит** — считается из свободных денег до следующего дохода с учётом обязательств.
- **Светлая и тёмная тема** — кнопка в правом нижнем углу.
- **PWA** — можно добавить на экран «Домой» на телефоне после публикации на хостинг.

## Начало ведения бюджета

Расчёт ведётся с **1 сентября 2026 года**. Обязательства за август 2026 считаются закрытыми; переноса долгов и резервов из августа нет.

## Быстрый старт

### Локально (без сервера)

Дважды щёлкните `index.html` — калькулятор откроется в браузере.  
Весь расчёт встроен в этот файл: **отдельно `budget-core.js` для работы страницы не нужен.**

> Для полной работы PWA (офлайн-кэш, установка на экран) нужен HTTP-сервер, см. ниже.

### Локальный сервер

**Python 3:**

```powershell
cd "путь\к\Бюджетный калькулятор"
python -m http.server 8080
```

Откройте в браузере: `http://localhost:8080`

**Node.js (npx):**

```powershell
npx --yes serve -p 8080
```

### На телефоне в одной Wi‑Fi сети

Запустите сервер на компьютере, узнайте локальный IP (например `192.168.1.5`) и откройте на телефоне:

`http://192.168.1.5:8080`

## Автотесты

Финансовое ядро проверяется автоматическими тестами (12 сценариев + инварианты).

**Python (рекомендуется, если нет Node.js):**

```powershell
cd "путь\к\Бюджетный калькулятор"
py budget_core_test.py
```

**Node.js:**

```powershell
node budget-core.test.js
```

## Публикация в интернет

Загрузите **все файлы** из папки на любой статический хостинг (GitHub Pages, Netlify, Vercel, Timeweb и т. д.). Ссылкой будет адрес сайта.

- Данные пользователя **не уходят на сервер** — только `localStorage` в браузере.
- Если поделиться ссылкой, у другого человека будет свой пустой калькулятор.

### GitHub Pages (пример)

1. Создайте репозиторий и запушьте проект.
2. Settings → Pages → Source: branch `main`, folder `/ (root)`.
3. Сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

## Как пользоваться

1. Выберите **планируемый месяц** в настройках.
2. Укажите **остаток на 1 сентября 2026** (если был).
3. Заполните **доходы** (день и сумма) и **постоянные расходы** (день оплаты и сумма).
4. При необходимости добавьте **разовые** и **повседневные** расходы.
5. Смотрите блок **«Что делать при каждом поступлении»** — там распределение по каждой зарплате.
6. Данные сохраняются автоматически в браузере; кнопка «Сохранить» дублирует запись в `localStorage`.

### Закрытые месяцы

Если месяц уже прошёл, суммы доходов в нём **фиксируются как факт** (поле только для чтения). Изменение шаблона дохода влияет на текущий и будущие месяцы, но не переписывает историю.
